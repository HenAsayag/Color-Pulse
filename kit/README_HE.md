# ערכת Color Smash

1. חלץ את כל ה-ZIP.
2. פתח את effects-preview.html כדי לבדוק את הנכסים והאפקטים. זו הדגמת אפקטים, לא המשחק המלא.
3. העבר ל-Codex או Claude Code את התיקייה כולה, כולל הסרטון בתיקיית reference.
4. העתק את כל תוכן MASTER_PROMPT.md לצ׳אט ובקש לבצע אותו.

החבילה כוללת פרומפט באנגלית, נכסי SVG, עשרה צלילי WAV מקוריים, מפרט תנועה, קובץ הגדרות, מודול אפקטים ותיעוד שימוש.

האפקטים הירוקים/אדומים/כתומים, הניקוד הצף והלבבות מבוססים על מה שנראה בסרטון. הסרטון קצר ולא מראה את כל חוקי המשחק: חוקים משלימים, תפריטים, תזמונים מדויקים וצלילים הוגדרו כהצעות הניתנות לשינוי. אין טענה לשחזור מלא של הקוד או הסאונד המקוריים.
